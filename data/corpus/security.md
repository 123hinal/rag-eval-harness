# Security and Compliance

## Certifications

FleetOps is SOC 2 Type II certified and undergoes annual penetration testing. GDPR and CCPA data processing agreements are available on Enterprise plans.

## Encryption

All data is encrypted in transit with TLS 1.2 or higher and at rest with AES-256. API secrets are stored hashed and can be rotated at any time from the dashboard without downtime.

## Data retention

Shipment and tracking data is retained for 13 months, then anonymized. Webhook delivery logs are kept for 90 days. Contact support for custom retention schedules on Enterprise plans.

## Access control

Role-based access control is available on all plans: Admin, Developer, and Viewer roles. SSO via SAML is supported on Growth and Enterprise.
